# E-commerce

Учебный проект на Python для практики объектно-ориентированного программирования (ООП). Проект моделирует товары, категории и заказы интернет-магазина, демонстрирует абстрактные классы, множественное наследование, работу с итераторами и загрузку данных из JSON-файла.

## Возможности

- Создание товаров с названием, описанием, ценой и количеством.
- Использование абстрактного базового класса `BaseProduct` для определения общей функциональности товаров.
- Использование миксина `ProductMixin` для вывода информации о создании объекта.
- Создание специализированных товаров: смартфонов и газонной травы.
- Множественное наследование класса `Product`.
- Формирование формального строкового представления объектов с помощью `__repr__()`.
- Создание категорий с товарами.
- Хранение списка товаров категории в приватном атрибуте.
- Подсчёт количества созданных категорий и добавленных товаров.
- Создание товаров из словаря с помощью `Product.new_product()`.
- Объединение товаров с одинаковым названием с обновлением количества и сохранением более высокой цены.
- Изменение цены с проверкой корректности и подтверждением при снижении.
- Подсчёт общей стоимости остатков двух товаров с помощью оператора `+`.
- Проверка совместимости типов при сложении товаров.
- Перебор товаров категории с помощью вспомогательного класса `CategoryIterator`.
- Создание заказов на один товар с указанием количества и расчётом итоговой стоимости.
- Использование абстрактного класса `BaseEntity` для общей функциональности категорий и заказов.
- Загрузка категорий и товаров из JSON-файла.
- Автоматизированное тестирование и проверка покрытия кода.

## Реализованный функционал

### BaseProduct

Абстрактный базовый класс для товаров.

- Содержит общие атрибуты товара: название, описание, цену и количество.
- Хранит цену в приватном атрибуте.
- Предоставляет свойство `price` для получения и изменения цены.
- Проверяет допустимость новой цены и запрашивает подтверждение при её снижении.
- Определяет абстрактный метод `__str__()`, который должен быть реализован в дочерних классах.

### ProductMixin

Миксин для вывода информации о создании объекта.

- Использует `super()` для передачи инициализации следующему классу в цепочке наследования.
- Выводит название класса созданного объекта и его формальное представление с помощью `__repr__()`.

### Product

Класс `Product` представляет товар и наследуется от `ProductMixin` и `BaseProduct`.

- Реализует строковое представление товара с помощью `__str__()`.
- Реализует формальное представление объекта с помощью `__repr__()`.
- Метод класса `new_product()` создаёт новый товар из словаря или объединяет его с существующим товаром с таким же названием.
- Метод `__add__()` вычисляет общую стоимость остатков двух товаров одного класса. При попытке сложить товары разных классов возникает `TypeError`.

### Smartphone

Класс `Smartphone` наследуется от `Product` и представляет смартфон.

Дополнительно содержит характеристики:

- `efficiency` — производительность.
- `model` — модель.
- `memory` — объём памяти.
- `color` — цвет.

Базовые атрибуты инициализируются через `super().__init__()`, а специализированные характеристики задаются в конструкторе наследника.

### LawnGrass

Класс `LawnGrass` наследуется от `Product` и представляет газонную траву.

Дополнительно содержит характеристики:

- `country` — страна-производитель.
- `germination_period` — срок прорастания.
- `color` — цвет.

Общие характеристики товара наследуются от `Product`, а дополнительные задаются в собственном конструкторе.

### BaseEntity

Абстрактный базовый класс для категорий и заказов.

- Определяет общий интерфейс для классов `Category` и `Order`.
- Содержит абстрактный метод `__str__()`, который реализуется в дочерних классах.

### Category

Класс `Category` представляет категорию товаров и наследуется от `BaseEntity`.

- Хранит название и описание категории.
- Содержит приватный список товаров.
- Метод `add_product()` добавляет объекты класса `Product` и его наследников.
- Для проверки принадлежности объекта к базовому классу используется `isinstance()`.
- При попытке добавить объект другого типа возникает `TypeError`.
- Свойство `products` возвращает текстовое представление товаров с указанием названия, цены и остатка.
- Свойство `products_list` возвращает копию списка товаров категории.
- Метод `__str__()` возвращает название категории и суммарное количество единиц товаров.
- Счётчики классов отслеживают количество категорий и добавленных товаров.

### Order

Класс `Order` представляет заказ одного товара и наследуется от `BaseEntity`.

- Хранит ссылку на объект товара.
- Содержит количество заказанных единиц товара.
- Рассчитывает итоговую стоимость заказа на основе цены товара и его количества.
- Проверяет корректность переданного товара и количества.
- Проверяет, достаточно ли товара на складе для оформления заказа.
- Метод `__str__()` возвращает информацию о заказе.

### CategoryIterator

Вспомогательный класс `CategoryIterator` позволяет последовательно перебирать товары категории.

- Принимает объект `Category` и получает копию списка его товаров.
- Метод `__iter__()` возвращает итератор.
- Метод `__next__()` возвращает следующий товар и вызывает `StopIteration`, когда товары заканчиваются.
- Поддерживает перебор товаров с помощью цикла `for`.

### Загрузка данных

Функция `load_categories_from_json()` загружает данные из JSON-файла и преобразует их в объекты `Category` и `Product`.

## Установка и запуск

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone <ссылка-на-репозиторий>
cd commerce
```

Установите зависимости:

```bash
poetry install
```

Запустите пример использования классов:

```bash
poetry run python main.py
```
