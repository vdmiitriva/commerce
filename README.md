# E-commerce

Учебный проект на Python для практики объектно-ориентированного программирования (ООП). Проект моделирует категории товаров интернет-магазина и загрузку данных из JSON-файла.

## Возможности

- Создание объектов товаров с названием, описанием, ценой и количеством.
- Создание категорий, содержащих список товаров.
- Подсчёт количества созданных категорий и товаров.
- Загрузка категорий и товаров из JSON-файла.
- Автоматизированное тестирование с помощью pytest.
- Проверка покрытия кода тестами и соблюдения стиля оформления.

## Используемые технологии

- Python
- Poetry — управление зависимостями и виртуальным окружением
- pytest — автоматизированное тестирование
- pytest-cov — измерение покрытия кода тестами
- Black — форматирование кода
- isort — сортировка импортов
- Flake8 — проверка стиля кода

## Установка и запуск

Клонируйте репозиторий и перейдите в его директорию:

```bash
git clone <ссылка-на-репозиторий>
cd commerce
```

Установите зависимости:

```bash
poetry install
```

## Тестирование

Запуск тестов:

```bash
poetry run pytest -v
```

Запуск тестов с отчётом о покрытии:

```bash
poetry run pytest --cov=ecommerce --cov-report=term-missing
```

## Проверка и форматирование кода

Форматирование:

```bash
poetry run black src tests
```

Сортировка импортов:

```bash
poetry run isort src tests
```
