# E-commerce

Учебный проект на Python для практики объектно-ориентированного программирования (ООП). Проект моделирует работу интернет-магазина: товары, категории и заказы. В нём реализованы абстрактные классы, наследование, миксины, итераторы, пользовательские исключения и загрузка данных из JSON-файла.

## Возможности

- Создание товаров, смартфонов и газонной травы.
- Проверка корректности цены и количества товара.
- Запрет создания товара с нулевым количеством.
- Использование абстрактных базовых классов `BaseProduct` и `BaseEntity`.
- Использование миксина `ProductMixin`.
- Множественное наследование.
- Создание и управление категориями товаров.
- Подсчёт количества категорий и товаров.
- Расчёт средней цены товаров категории с помощью `middle_price()`.
- Объединение товаров с одинаковым названием.
- Сложение товаров одного класса с помощью оператора `+`.
- Перебор товаров категории с помощью `CategoryIterator`.
- Создание заказов и расчёт их итоговой стоимости.
- Проверка доступного количества товара при оформлении заказа.
- Обработка ошибок с помощью пользовательского исключения `ZeroQuantityError`.
- Загрузка категорий и товаров из JSON-файла.
- Автоматизированное тестирование с проверкой покрытия кода.

## Реализованные классы и функции

### BaseProduct

Абстрактный базовый класс товаров. Содержит общие атрибуты товара, управляет ценой и проверяет корректность её изменения.

### ProductMixin

Миксин, который выводит информацию о создании объекта и использует `__repr__()` для его представления.

### Product

Основной класс товара.

- Содержит название, описание, цену и количество.
- Запрещает создание товара с нулевым количеством.
- Реализует `__str__()`, `__repr__()` и оператор `__add__()`.
- Метод `new_product()` создаёт товар из словаря или объединяет его с существующим товаром с таким же названием.

### Smartphone и LawnGrass

Специализированные классы товаров, наследующие `Product`.

`Smartphone` содержит характеристики производительности, модели, памяти и цвета.

`LawnGrass` содержит страну-производителя, срок прорастания и цвет.

### BaseEntity

Абстрактный базовый класс для категорий и заказов.

### Category

Класс категории товаров.

- Хранит название, описание и приватный список товаров.
- Добавляет товары с помощью `add_product()`.
- Проверяет тип добавляемого объекта.
- Возвращает информацию о товарах через свойство `products`.
- Возвращает копию списка товаров через `products_list`.
- Подсчитывает общее количество единиц товаров.
- Вычисляет среднюю цену товаров методом `middle_price()`.
- Поддерживает подсчёт количества созданных категорий и добавленных товаров.

### Order

Класс заказа одного товара.

- Проверяет тип товара и корректность количества.
- Проверяет наличие достаточного количества товара на складе.
- Рассчитывает итоговую стоимость заказа.
- Предоставляет строковое представление заказа через `__str__()`.

### CategoryIterator

Итератор для последовательного перебора товаров категории. Реализует методы `__iter__()` и `__next__()`.

### ZeroQuantityError

Пользовательский класс исключения для обработки ситуаций, когда товар с нулевым количеством пытаются добавить в категорию или заказ.

В обработке добавления используются конструкции `try`, `except`, `else` и `finally`.

### Загрузка данных

Функция `load_categories_from_json()` загружает данные из JSON-файла и преобразует их в объекты категорий и товаров.

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd commerce
```

Установите зависимости:

```bash
poetry install
```

Запустите пример использования проекта:

```bash
poetry run python main.py
```

## Тестирование

Запуск всех тестов:

```bash
poetry run pytest -v
```

Запуск тестов с проверкой покрытия:

```bash
poetry run pytest --cov=ecommerce --cov-report=term-missing
```

Тесты проверяют создание товаров, работу наследования и миксинов, изменение цены, сложение товаров, создание категорий и заказов, обработку исключений, работу итератора и загрузку данных из JSON.
